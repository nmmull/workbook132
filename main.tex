\chapter*{Preface}

The following is a collection of linear algebraic problems and
exercises for the course \texttt{CAS CS 132}: \textit{Geometric
  Algorithms} at Boston University.  As a student of this course, you
will hopefully work through nearly every problem in this document.
The problems are organized by topic and difficulty.  With regard to
difficulty there are four kinds of problems:
\begin{itemize}
\item Basic Exercises
\item True/False
\item More Difficult Problems
\item Challenge Problems
\end{itemize}
You should think of the basic exercises as quiz-level and the
true/false and difficult problems as exam-level.  A large proportion
of these problems and exercises have appeared on quizzes and exams in
the previous iterations of the course.  The challenge problems are
for those of who want to think a bit harder, and are purely for fun.

Many of these problems and exercises are based on those that appear in
\textit{Linear Algebra and Its Applications} by David Lay, Steven Lay
and Judi McDonald.  If a problem in this workbook is identical to one
that appears there, it is by accident or by coincidence.  Regardless,
we are in debt to this seminal text on undergraduate linear algebra.

Problems that require a computer or a calculator are labeled with the
symbol \faCalculator.  Otherwise, the expectation is that you should
be able to solve the problem by hand.

Solutions to these problems will never be made public, except during a
given semester when a problem is given in an assignment.  Also, during
the semester a student of the course is welcome to request a partial
solution any problem via our course public forum (usually Piazza).

I'd like to acknowledge folks who have contributed problems that
appear in this workbook, including Ed Chien, Mark Crovella, Vishesh
Jain, Ieva Sagaitis, and Abhinit Sati.  I also include David C. Lay,
Steven R. Lay, and Judi J. McDonald by proxy.

Lastly, even if it's not explicitly stated, \textbf{you should always
  show your work and justify your answer for every problem when
  submitting assignments in \texttt{CS132}.}  Happy exercising/problem
solving!

\section{True/False}

\trueFalseHeader

\begin{enumerate}[resume]
\item
  For any two matrices $A$ and $B$, if $A + B$ is defined then $A + B
  = B + A$.
\item
  For all matrices $A$ and $B$ in $\R^{m \times n}$ and $C$ in $\R^{n
    \times m}$, we have $(A + B + C^T)^T = C + B^T + A^T$.
\item
  For any square matrices $A$ and $B$ in $\R^{n \times n}$, if $A =
  A^T$ and $B = B^T$ then $AB = (AB)^T$.
\item
  For all matrices $A$ and $B$ such that $AB$ is defined, we have $AB
  \not = BA$.
\item
  For any matrix $A$, if $A$ has $n$ distinct eigenvalues, then it is
  invertible.
\item
  If $A\vx = \vb$ has a unique solution for every vector $\vb$ in the
  span of the columns of $A$, then $A$ is invertible.
\item
  For any matrix $A$ and vector $\vv$, if $\vv^T A$ is defined, then
  $A$ is single column.
\item
  For any matrices $A$ and $B$, if $A^{-1} = B^{-1}$, then $A = B$.
\item
  For any matrices $A$ and $B$, if there is a unique matrix $X$ such
  that $AX = B$, then $A$ is invertible.
\item
  For any matrix $A \in \R^{n \times n}$ and diagonal matrix $D \in
  \R^{n \times n}$, it must be that $AD = DA$.
\item
  If $A$ and $B$ are invertible, then so is $A + B$.
\item
  If $A$ and $B$ are invertible, then so is $BA$.
\item
  If $A$ and $B$ in $\R^{n \times n}$ are invertible, then so is
  $\begin{bmatrix}A & B \\ B & A\end{bmatrix}$, the matrix in $\R^{2n
      \times 2n}$ gotten by stacking copies of $A$ and $B$.
\item
  For any matrices $A$ and $B$, if there is a unique matrix $X$ such
  that $AX = B$, then $A$ is invertible.
\item
  For any matrices $A$ and $B$, if $AB = 0$, then $A = 0$ or $B = 0$.
\item
  For any matrices $A, B \in \mathbb R^{n \times n}$, if $AB = I$, then $BA = I$.
\item
  For any matrices $A$ and $B$, if $AB = BA$, then $A = B$.
\item
  If $A$ and $B$ are symmetric and $AB = BA$ then $AB$ is symmetric.
\item
  For any matrix $A \in \R^{n \times n}$, if the columns of $A^3$ span
  all of $\R^n$, then the columns of $A$ are linearly independent.
\item
  For any matrix $A \in \R^{n \times n}$, the matrix $A + A^T$ is
  symmetric.
\item
  If $AB$ and $BA$ are symmetric, then $A$ and $B$ are symmetric.
\item
  For any matrix $A \in \R^{n \times n}$, if $AA^T$ is
  symmetric, then so is $A$.
\item
  If $A \in \R^{n \times n}$ has zeros along its diagonal, then $A$ is
  not invertible.
\item
  If $A \in \R^{n \times n}$ has a row of all zeros, then $A$ is not
  invertible.
\item
  If $A \in \R^{2 \times 2}$ and $A^{-1}$ has integer entries then the
  determinant of $A$ is $1$.
\item
For any real numbers $a$ and $b$, the matrix $\begin{bmatrix} a & a^2
  \\ b & ab \end{bmatrix}$ is singular (i.e., not invertible).
\item
  For any square matrices $A$ and $B$, if $AB = I$, then $AB = BA$.
\item
  The \textbf{Hadamard product} of two matrices is defined as
  \begin{align*}
    (A \circ B)_{ij} = A_{ij} B_{ij}
  \end{align*}
  In other words, $A$ and $B$ are multiplied entry-wise.  For any
  invertible matrices $A$ and $B$, if $A \circ B$ is invertible, then
  $(A \circ B)^{-1} = A^{-1} \circ B^{-1}$.
\item
   For any matrices $A$ and $B$, if $AB = I$ then $A$ is invertible
   and $B = A^{-1}$.
\item
  For any two symmetric matrices $A$ and $B$, if $AB$ is defined then
  $(AB)^T = A^TB^T$.
\item
  A matrix $A \in \R^{n \times n}$ is invertible if and only if $A^T$
  is invertible.
\end{enumerate}

    equal, and that we can fit to the function $g_{\alpha_1,
      \alpha_2}$ using the least-squares method.
  \end{enumerate}
\end{enumerate}
